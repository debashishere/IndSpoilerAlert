## What to build

Implement the dynamic discount engine pricing simulator. Selecting an inventory lot from the dashboard opens an interactive sidebar or detail drawer in the UI. The drawer must display range sliders for the lot's remaining shelf life (days remaining) and inventory volume (quantity). Changing these sliders sends the new parameters via Express to the Python sidecar. The sidecar runs a real-time clearance optimization solver using `scipy.optimize` (evaluating simulated price elasticity for perishables vs. stables) and returns the recommended discount percentage and suggested liquidation unit price, which the UI immediately updates and plots.
