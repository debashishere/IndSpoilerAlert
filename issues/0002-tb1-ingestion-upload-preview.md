## What to build

Establish the project repository structure (Node.js Express backend, Python FastAPI sidecar service, and Vite + TypeScript frontend) and implement the end-to-end data flow for file uploads. A user must be able to upload a PDF or CSV invoice from the frontend UI. The Express backend receives the file, stores its metadata in MongoDB, and passes it to the Python sidecar. The sidecar runs IBM Docling to parse the document tables (using `TableFormerMode.ACCURATE` and `do_cell_matching = False`) and returns the raw rows and columns. The frontend UI displays this extracted table in a clean, scrollable grid preview.
