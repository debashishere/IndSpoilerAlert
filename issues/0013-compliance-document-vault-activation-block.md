## What to build

Implement a compliance document vault to manage food safety requirements for regulated inventory lots:
1. Create a `ComplianceDocument` collection (fields: `lotId`, `docType` enum `['COA', 'BATCH_RECORD', 'FSMA_ATTESTATION', 'ORGANIC_CERT']`, `s3Url`, `verified`).
2. Add `fdaRegulated`, `complianceDocs`, `temperatureMin`, and `temperatureMax` to the `InventoryLot` schema.
3. Build a document upload UI linked to the lot creation page that uploads PDFs to S3 and registers them as verified `ComplianceDocument` records.
4. Add a strict validation rule to the lot activation API: if `fdaRegulated` is `true`, prevent the lot status from transitioning to `'active'` unless there is at least one uploaded document of type `'COA'` and one of type `'BATCH_RECORD'`.
