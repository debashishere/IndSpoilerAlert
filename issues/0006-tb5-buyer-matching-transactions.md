## What to build

Implement the demand buyer matching recommendation and purchase simulation engine. In the inventory detail drawer, the system must display the Top 5 recommended retail buyers for the selected listing, sorted by match percentage. The matching algorithm runs on the Python sidecar and calculates the score based on a hybrid of buyer tag preferences, distance/shelf-life rules, and past purchase history loaded from MongoDB. Next to each buyer, a "Notify & Sell" button allows the user to trigger a purchase request. This creates an `Offer` (marked as accepted), an `Award`, and a `Shipment` log, setting the `InventoryLot` status to `sold` in MongoDB.
