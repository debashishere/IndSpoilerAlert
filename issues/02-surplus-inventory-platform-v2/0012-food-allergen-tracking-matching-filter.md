## What to build

Integrate allergen tracking into product listings and buyer matches to comply with food safety:
1. Add `allergens: [String]` to the `ProductMaster` schema.
2. Add `excludedAllergens: [String]` to the `Buyer` schema.
3. Update the smart buyer matching recommendation logic (both the Python scoring sidecar and Express matching endpoints) to exclude a buyer if any of their `excludedAllergens` are listed in the product's `allergens` list.
4. Update the supplier and buyer UI pages to manage and display product allergens and buyer allergen preferences.

## Acceptance criteria

- [x] `ProductMaster` model supports the `allergens` array field.
- [x] `Buyer` model supports the `excludedAllergens` array field.
- [x] Buyer matching scoring algorithm excludes buyers from recommendations when there is a collision between product allergens and buyer exclusions.
- [x] Frontend allows sellers to view allergens on products and buyers to specify allergen exclusions in their profiles.
- [x] Unit and integration tests verify that buyers with allergen conflicts are correctly filtered out from opportunities.
