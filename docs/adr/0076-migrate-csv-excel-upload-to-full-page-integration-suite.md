# Migrate CSV & Excel Upload to Full-Page Integration Suite

Manual CSV/Excel batch ingestion was previously confined to an ephemeral modal overlay (`UnifiedIngestionModal`) under ADR 0072. We decided to supersede that model and promote CSV & Excel Ingestion to a first-class 4th tab (`?tab=ingestion&connector=csv-upload`) within the full-page Integration Management Suite alongside Google Sheets, Zapier, and Doc Scanner. All pipeline-level upload triggers and events universally deep-link into this suite with their target pre-selected. This standardizes all ingestion mechanisms under the unified Four-Quadrant architecture (ADR 0071), offering dedicated ingestion telemetry, multi-pipeline target routing (Inventory, Sales, Buyers), batch history audit roster, and in-situ schema mapping without screen hopping.
