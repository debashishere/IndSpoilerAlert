# Zapier Connected Roster and Payload Audit Model

To ensure operational transparency and rapid debugging for event-driven third-party integrations, the Zapier full-page view implements a dual telemetry layer: a Connected Zaps Roster tracking registered feeds, trigger sources, lot counts, and schema mappings, paired with an inline, collapsible Webhook Ingress Payload Log detailing recent HTTP deliveries, response codes, latencies, and payload samples.
